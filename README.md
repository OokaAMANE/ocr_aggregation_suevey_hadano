# アンケート OCR・集計ツール（秦野市 交通アンケート）

手書きで回答された紙のアンケート用紙をスキャンして取り込み、AI（Claude の画像認識）で回答を読み取り、
担当者が画面で確認・修正したうえで、単純集計・クロス集計・Excel 出力までを行う Web ツールです。

## 対応している様式

`アンケート用紙.xlsx` の各シートを、次の様式として定義しています（`app/surveys/*.json`）。
「（没）」シートと、表の部品用シート（Sheet1 など）は対象外です。

| 様式ID | 様式名 | 元シート | 既定ページ数 |
|---|---|---|---|
| `chimura_v2` | 千村・峠地区の交通に関するアンケート（Ver.2） | 千村 （新） (Ver.2) | 1 |
| `chimura_new` | 千村・峠地区の交通再編に関するアンケート | 千村 （新） | 2 |
| `taxi_nishi_chimura` | コミュニティタクシー（渋沢駅・秦野赤十字病院ルート）［西・千村］ | 西・千村 (渋沢中第1追加) | 1 |
| `taxi_nishi_chimura_old` | 同上［西・千村（渋沢中第1なし）］ | 西・千村 | 1 |
| `taxi_minami` | 同上［南］ | 南 | 1 |
| `taxi_oone` | コミュニティタクシー（おおね台ルート）［大根］ | 大根 | 1 |

様式が増えた・選択肢が変わった場合は、JSON をコピーして編集すれば画面・AI 読み取り・集計・Excel 出力すべてに反映されます（書式は `app/surveys.py` の先頭コメントを参照）。

## 使い方

1. **取り込み**: 画面上部で様式を選び、スキャンした PDF / JPEG / PNG / TIFF をドラッグ＆ドロップします。
   複数ページの PDF は先頭から「1人あたりのページ数」ごとに1人分として区切ります（両面印刷の様式は 2）。
   「回収区分」（例: 第1回回収、〇〇自治会）を入れておくと、一覧や Excel で区別できます。
2. **AI 読み取り**: 取り込み時に読み取り方法を選びます。
   - **バッチで読み取る（おすすめ）**: 料金が半額。まとめて送信し、結果は通常1時間以内（最大24時間）に届きます。
     ツールが1分ごとに結果を確認し、届いた分から一覧に反映します。途中でツールを止めても、再起動すれば続きから受け取ります。
   - **すぐに読み取る**: 通常料金。1枚ずつ数十秒で読み取ります（同時に3件ずつ）。試し読みや急ぐとき向け。
   - **読み取らない**: 画像だけ取り込み、手入力します。

   読み取りが終わると、次の状態になります。
   - **読取済（未確認）**: AI が迷った箇所なし
   - **要確認**: AI が判読に自信がない設問がある／単一回答の設問に複数チェックがある／欄外の書き込みなど
   - **エラー**: 読み取り失敗（一覧からまとめてバッチで再読み取りできます。1件ずつなら確認画面の「AIで再読み取り」）
3. **確認・修正**: 一覧の「未確認の回答を順に確認」から、左に用紙画像・右に読み取り結果を並べて確認します。
   要確認の設問は黄色で表示されます。修正後 **Ctrl+Enter**（確認済にして次へ）で次の用紙に進みます。
   問題なしと判定された回答は「一括で確認済にする」こともできます。
4. **集計・出力**: 設問ごとの件数・割合のグラフ、時間帯のヒートマップ、目的地・停留所の件数、自由意見の一覧を表示します。
   性別・年齢・自治会区での絞り込みと、単一回答設問別のクロス集計ができます。
   「Excelで出力」で、単純集計／属性別クロス集計／自由記述／回答データ（1人1行）のシートを持つブックをダウンロードします。

用紙がない回答（Web 回答・聞き取りなど）は、取り込み画面の「手入力で1件追加」から入力できます。

### 集計のルール

- 割合の母数は集計対象の回答者数（無回答を含む）です。複数回答の設問は合計が 100% を超えます。
- 単一回答の設問に複数チェックがある場合は「複数回答（無効）」として別に数えます（確認画面で修正すれば正しく集計されます）。
- 目的地の表は、種別の□にチェックがなくても目的地・停留所が書かれていれば、その種別の回答ありとして数えます。
- 千村（新）問4 は用紙に「時間が読めない（バスが遅れるなど）」が2か所印刷されているため、1つの選択肢にまとめています。
- 千村 Ver.2 問6 は「最も重視すること」ですが、複数チェックも全て数える複数回答として扱っています。

## セットアップ

Python 3.10 以上が必要です。

```bash
pip install -r requirements.txt
```

AI 読み取りを使うには Anthropic の API キーを設定します（未設定でも、取り込み・手入力・集計は使えます）。
いちばん簡単なのは、`.env.example` を `.env` という名前でコピーし、`ANTHROPIC_API_KEY=` の後ろにキーを書く方法です
（`start.bat` と同じフォルダに置きます。キーを含むので共有しないでください）。環境変数 `ANTHROPIC_API_KEY` で設定しても構いません。

```bash
export ANTHROPIC_API_KEY=sk-ant-...
```

起動（Windows は `start.bat` をダブルクリック）:

```bash
./start.sh
```

ブラウザで http://127.0.0.1:8000 を開きます。

### 設定（環境変数）

| 変数 | 既定値 | 内容 |
|---|---|---|
| `ANTHROPIC_API_KEY` | なし | AI 読み取りに使う API キー |
| `OCR_MODEL` | `claude-opus-5-5` | 読み取りに使うモデル |
| `OCR_EFFORT` | `high` | 読み取りの丁寧さ（`low` / `medium` / `high` / `xhigh` / `max`）。下げると速く安くなる |
| `OCR_CONCURRENCY` | `3` | 「すぐに読み取る」で同時に読み取る件数 |
| `OCR_BATCH_POLL_SECONDS` | `60` | バッチの結果を確認する間隔（秒） |
| `OCR_BATCH_MAX_MB` | `100` | 1回のバッチ送信の大きさの上限（API の上限は 256MB）。超える分は自動で分けて送る |
| `SURVEY_DATA_DIR` | `./data` | 回答データ（SQLite）と用紙画像の保存先 |

これらの設定は `.env` に `変数名=値` の形で書いても有効です（環境変数が設定されていればそちらが優先）。

AI がまれに安全フィルタで読み取りを断った場合、「すぐに読み取る」では API 側で推奨の別モデルに自動で切り替えて再実行します（`fallbacks: "default"`、対応モデルのみ）。
バッチではこの仕組みが使えないため、その用紙はエラーになります。確認画面の「AIで再読み取り」で読み直してください。

## データの取り扱い

- 回答データと用紙画像は `data/` フォルダ（`SURVEY_DATA_DIR`）にのみ保存されます。バックアップはこのフォルダをコピーしてください。
- AI 読み取りでは、用紙画像を Anthropic の API に送信します。庁内の情報セキュリティポリシーで外部送信が認められているか確認のうえ利用してください。
  送信できない場合は API キーを設定せずに起動すれば、画像の取り込みと手入力による集計だけを行えます。
- 既定では自分の PC（127.0.0.1）からのみアクセスできます。庁内の他の PC から使う場合は `--host 0.0.0.0` で起動しますが、
  ログイン機能はないため、アクセスできる範囲をネットワーク側で制限してください。

## 開発

```bash
pip install -r requirements-dev.txt
python -m pytest
```

構成:

- `app/main.py` — Web API（FastAPI）
- `app/jobs.py` — AI 読み取りの実行（通常読み取りのキュー、バッチの送信・結果受け取り）
- `app/surveys.py` — 様式定義の読み込み、回答データの形・正規化、AI 用スキーマ
- `app/ocr.py` — Claude による用紙の読み取り（構造化出力で様式どおりの JSON を受け取る）
- `app/aggregate.py` — 単純集計・クロス集計
- `app/export.py` — Excel / CSV 出力
- `app/static/` — 画面（HTML / CSS / JavaScript、外部ライブラリなし）
- `app/surveys/*.json` — 様式定義
